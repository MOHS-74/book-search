# 📚 Book Search

A responsive book search website built as part of a Frontend Challenge.

The project allows users to search for books, browse the results, and view additional information about each book.

## 🚀 Features

- 🔎 Search for books
- 📚 Display book search results
- 🖼️ Book covers
- ✍️ Author information
- 📅 First publication year
- 📖 Book details modal
- ⏳ Loading state
- ❌ No results state
- ⚠️ Error handling
- 📱 Responsive design
- 🎨 Hover effects and animations

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Open Library API
- Gemini API

## 🔌 APIs

### Open Library API

Used to search for books and retrieve book information.

### Gemini API

Used to generate short book descriptions inside the book details modal.

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile

## 🎯 Challenge Goal

The goal of this project was not only to build a working website, but also to practice:

- Working with APIs
- Fetching and displaying dynamic data
- DOM manipulation
- Handling loading and error states
- Creating responsive layouts
- Building interactive UI components
- Debugging and problem solving
